# Recordings

Fallback screen captures. **Every live segment must have one before the talk** — in a 40-minute slot,
debugging on stage is not an option.

Expected files:

```
demo-a-slice-round-trip.mp4
demo-b-price-path-comparison.mp4
demo-c-admin-console.mp4
ai-delist-instrument-slice.mp4
```

Record them during the rehearsal run described in `../demo-script.md`, from a wiped database, in the same
window layout you will present in. Same terminal font size, same browser zoom — a recording that looks
different from the live windows tells the room you switched.

Keep them out of git if they are large; this directory is for the presenting machine.
